Phantom Shift: Evolution

“The game doesn’t just get harder… it gets smarter based on YOU.”

Phantom Shift: Evolution is a high-graphics, AI-driven platformer game that adapts dynamically to the player's behavior, emotions, and playstyle in real time.
Built as an advanced project combining game development + artificial intelligence, the game delivers a personalized and immersive experience.

🧠 Core Concept

Unlike traditional games with fixed difficulty, Phantom Shift uses:

Player behavior tracking
Emotional state modeling (FSM)
Adaptive AI systems

👉 to analyze, predict, and respond to how you play.

🎮 Game Features
🕹️ Level-Based Gameplay
10 progressively challenging levels
Each level introduces new AI capabilities
Final boss adapts to player strategy in real time
🎨 High-End Graphics
2.5D cinematic visuals
Dynamic lighting & shadows
Fog, particles, and ghost effects
Emotion-based environment changes
⚡ Smooth Controls
Responsive movement system
Jump buffering & coyote time
Dash, wall slide, and wall jump mechanics
Camera effects & screen feedback
🤖 AI Systems Used
1. Player Behavior Tracking
Movement patterns
Reaction time
Success/failure rate
2. Pattern Recognition

Classifies player type:

Aggressive
Defensive
Explorer
Panic player
3. Finite State Machine (FSM) – Emotion Engine

Tracks player emotions:

Calm
Tense
Fear
Panic

💡 Affects:

Lighting
Sound
Enemy behavior
4. Utility AI (Decision Making)

Enemies dynamically choose actions:

Attack
Chase
Hide
Ambush
5. Behavior Tree

Structured enemy logic:

Patrol
Chase
Ambush
Retreat
6. A* Pathfinding
Intelligent enemy navigation
Real-time path updates
7. Adaptive Difficulty System
Increases difficulty if player performs well
Reduces intensity if player struggles
8. Bayesian Prediction
Predicts player’s next move
Adjusts enemy strategy in advance
